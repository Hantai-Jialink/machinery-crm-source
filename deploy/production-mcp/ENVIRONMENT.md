# 生产环境变量清单（不含取值）

| 变量名 | 来源 |
| --- | --- |
| `NODE_ENV`, `PORT`, `HOSTNAME`, `PRODUCTION_ENV_FILE` | 本灰度包固定运行参数 |
| `MCP_IMAGE`, `MCP_IMAGE_ARCHIVE`, `MCP_IMAGE_IDENTITY_PROOF` | Artifact 内固定 MCP RepoTag、Docker 归档绝对路径及 RepoTags/Config Digest/SHA256 身份证明 |
| `CRM_DATABASE` | 现有正式 CRM 数据库标识 |
| `DATABASE_URL` | 新建的业务只读数据库账户：仅允许工具涉及表的 `SELECT` |
| `MCP_AUDIT_DATABASE_URL` | 独立审计账户：仅允许对 `operation_logs` 执行 `INSERT` |
| `MYSQL_CLIENT_DEFAULTS_FILE`, `MCP_AUDIT_MYSQL_CLIENT_DEFAULTS_FILE` | 服务器已有、权限受限的只读与审计 MySQL 客户端配置文件 |
| `MYSQL_CLIENT_IMAGE`, `MCP_DATABASE_GRANT_HOST`, `MCP_DATABASE_READ_USER`, `MCP_DATABASE_AUDIT_USER` | 固定 MySQL 8.0.44 AMD64 客户端摘要、MCP 容器实际来源地址和两个最小权限账户名 |
| `AUTH_SECRET`, `AUTH_URL` | 现有正式 CRM/ERP 身份服务配置 |
| `MCP_AUDIT_USER_ID` | 现有正式超级管理员的稳定用户 ID |
| `MCP_API_KEYS_JSON` | 新建的专用 MCP 服务 Key（仅保存哈希） |
| `MCP_LEGACY_USER_BOUND_AUTH`, `MCP_TOOL_MODE`, `MCP_TOOL_ALLOWLIST`, `MCP_QUERY_TIMEOUT_MS`, `MCP_ALLOWED_HOSTS`, `MCP_ALLOWED_ORIGINS` | 本灰度范围、正式 DNS 与网络边界 |
| `AGENT_AUTH_ISSUER`, `AGENT_AUTH_AUDIENCE`, `AGENT_AUTH_TOKEN_TTL_SECONDS`, `AGENT_AUTH_ACTIVE_KID`, `AGENT_AUTH_KEYS_JSON` | 新建的 Agent Gateway Ed25519 短期断言密钥集与固定策略 |
| `REDIS_PASSWORD`, `AGENT_AUTH_REDIS_URL`, `AGENT_AUTH_REDIS_PREFIX` | 本灰度包独立、带密码 Redis 服务与一次性 JTI 前缀 |
| `AGENT_GATEWAY_FASTGPT_CHAT_URL`, `AGENT_GATEWAY_FASTGPT_API_KEY` | 已完成精确 4.15.2 兼容验证的 Canary FastGPT 与其专用服务 Key |
| `FASTGPT_SOURCE_COMMIT`, `FASTGPT_BASE_IMAGE`, `FASTGPT_CANARY_IMAGE`, `FASTGPT_CANARY_ARCHIVE`, `FASTGPT_CANARY_AGENT_ENGINE` | 固定 v4.15.2 提交、官方 AMD64 镜像、Artifact RepoTag、Docker archive 绝对路径及允许的 Agent 引擎；不可变身份以归档证明为准 |
| `CANARY_MONGO_ROOT_USER`, `CANARY_MONGO_ROOT_PASSWORD`, `CANARY_MONGO_DATABASE`, `CANARY_MONGO_REPLICA_KEY_FILE`, `CANARY_REDIS_PASSWORD`, `CANARY_MINIO_ROOT_USER`, `CANARY_MINIO_ROOT_PASSWORD`, `CANARY_STORAGE_PUBLIC_BUCKET`, `CANARY_STORAGE_PRIVATE_BUCKET`, `CANARY_FASTGPT_ROOT_KEY`, `CANARY_FASTGPT_TOKEN_KEY`, `CANARY_FASTGPT_FILE_TOKEN_KEY`, `CANARY_FASTGPT_AES_KEY`, `CANARY_FASTGPT_INVOKE_TOKEN_SECRET` | 仅属于 Canary 的独立数据面与用途隔离密钥；Invoke 密钥至少 32 字符且不得与其他 Canary 密钥复用；Mongo 变量只保存服务器上 `0600` Keyfile 的绝对路径，禁止与正式 FastGPT 复用 |
| `AGENT_GATEWAY_MAX_REQUEST_BYTES`, `AGENT_GATEWAY_RATE_LIMIT_PER_MINUTE`, `AGENT_GATEWAY_ALLOWED_ORIGINS`, `AGENT_GATEWAY_ALLOWED_ROLES` | 第一阶段灰度策略：仅正式 CRM 域名、仅 `SUPER_ADMIN` |
| `FORMAL_FASTGPT_HEALTH_URL`, `FASTGPT_CANARY_HEALTH_URL`, `FASTGPT_CANARY_COMPATIBILITY_PROOF` | 正式 FastGPT 3100 健康检查、Canary 健康检查及兼容性证明文件 |
| `FASTGPT_DIR`, `CRM_DIR`, `NGINX_GATEWAY_INCLUDE`, `BACKUP_ROOT` | 服务器预检查确认后的现有目录与新 Nginx include 路径 |
| `FORMAL_FASTGPT_*_FINGERPRINT`, `CANARY_FASTGPT_*_FINGERPRINT` | DBA/运维对 Mongo、Redis、对象存储、应用、用户、会话和 API Key 数据面生成的不可逆指纹；同类指纹必须不同 |

禁止把真实 `.env.production`、Cookie Jar、FastGPT 服务 Key、Ed25519 私钥或数据库口令放入本目录、Git、ZIP 或工单。
